# Demo hub

A ready-made hub (`acme-hub`) connecting two small projects: `widgets`, an app with an importer plan
and a goal, and `gadgets`, its website. Each folder stands in for its own git repository.

```bash
reinstall-hub priorities --hub examples/demo/acme-hub
```

[docs/hub.md](../../docs/hub.md#try-it) explains the order you get and what to try next.
`git checkout examples/demo` puts it back after you've played with it.
